# Reacharound (Minecraft 1.7.10)

Мод для сборки на Forge 1.7.10 (GTNH-окружение). Два режима установки блоков:

## 1. Режим как в Quark (включён по умолчанию)

Если в руке блок, а прицел смотрит **в пустоту** рядом с краем блока, блок всё равно ставится:

* **Горизонтально.** Вы стоите на краю и смотрите чуть дальше края: блок встаёт в клетку перед последним блоком
  (мост без приседания). Луч сдвигается назад на `leniency` (0.5 блока, как в Quark).
* **Вертикально** (если не смотрите вверх). Блок встаёт **под** блоком, на который "достаёт" поднятый на `leniency`
  луч, если эта клетка больше чем на 1 блок ниже ваших ног. Так можно ставить блоки под край, на котором вы стоите.
* **Индикатор.** Возле прицела появляется значок-уголки (горизонтальный или вертикальный вариант, как в Quark),
  пока установка возможна.
* Работает **только на клиенте**: серверу ничего ставить не нужно, он получает обычный клик по блоку.
* Блоки в левой руке (Backhand) тоже ставятся, но индикатор показывает только предмет в основной руке.

## 2. Режим "край грани" (по умолчанию выключен)

Если навести прицел на самый край верхней (или нижней) грани блока, блок встаёт сбоку. Включается в конфиге
(`edge_snap.enabled = true`), нужен на клиенте и на сервере. Плиты продолжают линию той же половинкой.

## Настройки (`config/reacharound.cfg`)

Если вы запускали прошлую версию, удалите старый `config/reacharound.cfg`, чтобы создался новый.

| Раздел | Параметр | По умолчанию | Что делает |
|---|---|---|---|
| quark_style | `enabled` | true | режим как в Quark |
| quark_style | `leniency` | 0.5 | на сколько блоков за край можно целиться |
| quark_style | `showIndicator` | true | значок возле прицела |
| edge_snap | `enabled` | false | режим "край грани" |
| edge_snap | `edgeMargin` | 0.1 | как близко к краю грани должен быть прицел |
| edge_snap | `allowNearEdges` | false | разрешить ближний к вам край |
| edge_snap | `affectSideFaces` | false | работать и на стенах |
| edge_snap | `requireSneaking` | false | только при приседании |

## Лицензия и авторство

Алгоритм режима и иконки индикатора основаны на Quark (Vazkii / Violet Moon, CC BY-NC-SA 3.0).
См. `NOTICE.md`: нужно сохранять указание авторства, не использовать коммерчески и распространять изменения на тех же
условиях. Для личной сборки это не ограничение.

## Известные ограничения

* Рамка выделения блока не меняется (при режиме "край грани").
* Если рядом нет блока, до которого достаёт сдвинутый луч, установка не сработает: это поведение Quark.
